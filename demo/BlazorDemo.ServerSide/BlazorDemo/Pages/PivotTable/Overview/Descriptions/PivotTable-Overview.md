The Blazor [Pivot Table](https://docs.devexpress.com/Blazor/DevExpress.Blazor.PivotTable.DxPivotTable) UI component summarizes data from the underlying data source and presents the results in cross-tabulated format. It ships with the following features/capabilities:

* High-performance data engine
* Data sorting support
* DateTime, numeric, alphabetic, and custom group intervals
* Configurable totals and grand totals
* Built-in scroll bar and sticky Header/Row Value areas
* Virtual scrolling support
* Value formatting and integrated templates

In this demo, the Pivot Table allows you to browse prices and discounts for different car models per years and quarters. It also calculates and displays sub-totals and grand totals for these data.
