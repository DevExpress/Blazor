If the DevExpress Blazor [Pivot Table](https://docs.devexpress.com/Blazor/DevExpress.Blazor.PivotTable.DxPivotTable) displays a large number of data cells, enable virtual scrolling to improve performance. Set the [VirtualScrollingEnabled](https://docs.devexpress.com/Blazor/DevExpress.Blazor.PivotTable.DxPivotTable.VirtualScrollingEnabled) property to `true`. In this mode, the Pivot Table renders data on demand as a user scrolls through rows/columns.
