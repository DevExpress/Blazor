In many instances, users only need a limited set of time-related selection options. For example, meetings usually start every 30 minutes – as such, displaying 60-minute options is not necessary. You can limit time picker selection options by setting intervals for hours, minutes, or seconds using the following properties properties: 

* [HourIncrement](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxTimeEdit-1.HourIncrement)
* [MinuteIncrement](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxTimeEdit-1.MinuteIncrement)
* [SecondIncrement](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxTimeEdit-1.SecondIncrement)

In this demo, our Blazor Time Edit component allows you to select values using 10-minute and 15-second intervals.
