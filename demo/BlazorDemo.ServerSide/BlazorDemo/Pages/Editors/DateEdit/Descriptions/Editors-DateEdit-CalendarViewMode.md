The **DevExpress Blazor Date Edit** component allows users to select/specify date values (day, month, and/or year). Thanks to its flexibility, you can control available Date Edit "views" to address the following requirements:

* Disable Day selection: Users can only select/specify a year and month value.
* Disable Day and Month selection: Users can only select/specify a year value.

To customize/control views available to users, use the [CalendarViewMode](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxDateEdit-1.CalendarViewMode) property.

Note: To help illustrate the flexibility of our Blazor Date Edit control, day selection has been disabled in this demo (users can only select month/year values).
