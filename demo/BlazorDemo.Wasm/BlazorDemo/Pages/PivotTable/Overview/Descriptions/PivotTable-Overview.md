Our new Blazor [Pivot Table](https://docs.devexpress.com/Blazor/405245/pivot-table) UI component (Community Technology Preview) summarizes data from the underlying data source and presents results using a cross-tabulated UI metaphor. It ships with the following integrated features/capabilities:

* High-performance data engine
* [Data sorting support](https://docs.devexpress.com/Blazor/405367/components/pivottable/filter-data#sort-data)
* [Data filters](https://docs.devexpress.com/Blazor/405367/components/pivottable/filter-data#filter-data)
* DateTime, numeric, alphabetic, and custom [group intervals](https://docs.devexpress.com/Blazor/405367/components/pivottable/filter-data?v=25.1#group-data)
* Configurable [totals and grand totals](https://docs.devexpress.com/Blazor/405459/components/pivottable/pivot-table-basics#totals-grand-totals)
* [Field customization in the UI](https://docs.devexpress.com/Blazor/405459/components/pivottable/pivot-table-basics#field-customization-in-the-ui)
* Built-in scroll bar and sticky Header/Row Value areas
* [Virtual scrolling support](https://docs.devexpress.com/Blazor/405475/)
* [Value formatting](https://docs.devexpress.com/Blazor/DevExpress.Blazor.PivotTable.DxPivotTableField.CellFormat) and [integrated templates](https://docs.devexpress.com/Blazor/405474/components/pivottable/templates)
* [Persistent layout](https://docs.devexpress.com/Blazor/405458/components/pivottable/save-and-restore-layout)
 
In this demo, the Pivot Table allows you to browse/analyze prices and discounts across different car models (by quarter/year). It also calculates and displays sub-totals and grand totals for relevant data points.
