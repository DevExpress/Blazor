The DevExpress Blazor [Scheduler](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxScheduler) component allows you to display detailed snapshots of events/appointments within your DevExpress-powered web application across a single day, week, or month.

## Key Features and Capabilities

* Accessibility compliance
* Runtime and remote data support
* Multiple view types: Day, Week, Work Week, Month, and Timeline
* Drag & drop support
* One-time and recurring appointments
* Appointment management: create, edit, select, and delete operations
* Resource support
* Integrated templates and CSS customization
* Configurable toolbar
* Keyboard support
