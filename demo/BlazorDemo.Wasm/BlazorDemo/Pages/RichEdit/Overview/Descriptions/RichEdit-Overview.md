The DevExpress [Rich Text Editor](https://www.devexpress.com/blazor/rich-text-editor/) for Blazor is a Microsoft Word-inspired rich text editor/word processor with comprehensive text formatting options.

## Key Features and Capabilities

* Create, open, and save documents in DOCX, RTF, TXT, and HTML formats
* Change character and paragraph formatting
* Work with floating objects (images and text boxes)
* Zoom and print documents
* Switch to Simple View (hide pagination and layout control elements and use entire component area to display the document)
* Mail merge
* Spell check
* Configurable toolbar/ribbon
* Customizable context menu
* AI-powered extensions
* Keyboard support
* Localization
