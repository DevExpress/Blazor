The [DxToastProvider](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxToastProvider) component allows you to define common toast settings. The following properties specify toast size and position:

* [HorizontalAlignment](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxToastProvider.HorizontalAlignment)
* [VerticalAlignment](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxToastProvider.VerticalAlignment)
* [Width](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxToastProvider.Width)
